# Enter the Field | Φ369 Research Archive

A public GitHub Pages front end for Michael Hughes' Zenodo research records.

## What it does

- Queries Zenodo's public REST API for multiple creator-name variants.
- Keeps a curated fallback list of known Zenodo records for inconsistent author formatting.
- Provides search, category/type filters, sorting, DOI links, and an in-page PDF viewer.
- Keeps Zenodo as the authoritative source. This repository stores presentation code, not duplicate research claims.

## GitHub Pages

This is a zero-build static site. Publish with **Settings → Pages → Deploy from a branch → main → /(root)**.

## Philosophy

**Question → Build → Test → Share**

The archive is deliberately interdisciplinary: physics, AI systems, software, governance, methods, creative research, datasets, posters, and future work can all live here.
